# Sửa văn bản trong file

Đọc lại bản đang ở trên đĩa, kể cả khi vừa sửa trong phiên. File dài thì đọc từng phần cho tới hết. Giữ code, lệnh, đường dẫn, link và YAML khi sửa văn xuôi. Nếu phải trả Markdown có khối code trong tin nhắn, bọc ngoài bằng bốn dấu backtick. Sau khi ghi, đọc lại phần vừa sửa trên đĩa và đối chiếu với bản gốc. Xong thì báo đã rà bao nhiêu mục và phần nào còn dang dở.
